# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could corrupt saves, execute unintended code, expose local data, or compromise a user's game installation.

Use GitHub's **Report a vulnerability** option in the repository Security tab to submit a private security advisory. Include the affected plugin/version, reproduction steps, impact, and any proposed mitigation. Do not attach private saves or unredacted logs unless they are essential and you understand what they contain.

## Supported versions

Security fixes target the latest published release. Older prereleases may receive documentation or upgrade guidance but are not maintained as separate supported lines.

## Scope

This policy covers code and release artifacts published by OrbOfCreation-ModSuite. Issues in Orb of Creation, BepInEx, Harmony, Steam, Proton, or other third-party software should be reported to their respective maintainers.
