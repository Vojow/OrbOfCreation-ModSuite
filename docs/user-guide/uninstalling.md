# Uninstalling

[Back to documentation](../README.md)

1. Close the game.
2. Remove `OrbAutomata.dll`, `OrbModConfig.dll`, and `OrbModding.Common.dll` from `BepInEx/plugins/OrbAutomata`.
3. Retain or delete their configuration files under `BepInEx/config` as preferred.

The released mods do not add custom save-file records. Keep a save backup until you have confirmed that the unmodified game loads normally.
