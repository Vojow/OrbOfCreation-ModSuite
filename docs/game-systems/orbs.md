# Orbs

Orb XP feeds a **global level bar along the very bottom of the screen**, below every tab. Each level
of that bar yields an orb.

- **Each orb research level costs exactly one orb.**
- **Orb research is the disciplines of magic** — the classes the rest of the game is organised
  around.
- A great deal of later content gates on having a specific number of levels in a specific discipline,
  and a run never produces enough orbs to cover everything. Orb allocation is permanently a question
  of which parts of the game you are choosing to reach.
- A new-game-plus run starts with some bonus orb levels, some pre-allocated and some free to place.
  Free bonus levels do not advance the paid cost curve; see
  [attributes-and-upgrades.md](attributes-and-upgrades.md).
