# Achievement Strength

Achievement Strength is a single number earned by completing achievement levels, and it pays twice:

- **`+1 %` global resource gain per point**, applied to the `All` resource type — e.g., 28 points is
  exactly ×1.28 All Resources Gained. This is why a brand-new resource in a later run can already
  read `Gain 128 %` with no keyword upgrade in sight.
- **`+1` starting Time Advancement per point**, once the time-reset prerequisite is met.

It survives every reset.
