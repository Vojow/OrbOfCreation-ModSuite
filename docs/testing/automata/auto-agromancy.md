# Auto Agromancy testing

[Automata testing](README.md) · [Runtime protocol](../runtime-validation.md) ·
[Migration tracker](../../plans/auto-agromancy-migration.md)

Auto Agromancy is disabled by default and uses the shared ServiceCycle world
source. Its portable evidence is grouped under `FullyQualifiedName~AutoAgromancy`.

Required focused coverage:

- true-spend and full-speed drain math, including quality and exponent lists;
- compact-planner parity with the preserved adapter oracle;
- atomic active-pair, ordered-cost, and modifier publication;
- direct-increase observation and deterministic trigger sweeps;
- configuration, lifecycle, ownership, fingerprint, postcondition, rollback,
  and mutation-quarantine guards;
- exact plot-add and verified Auto Harvest trigger producers; and
- independent feature status, bounded-one dispatch, and registration order.

The full portable gate does not admit a new installed game build. Before
describing the feature as validated in-game, run the installed contract audit
and the Auto Agromancy scenarios in the migration tracker on a disposable save.
