# strategy charter

Opinionated: how to play Orb of Creation well. Builds on `../game-systems/` and never
re-explains mechanics — link to them.

- When a page disagrees with observed reality, the page is wrong: fix it in the same change
  that proves it wrong.
- Moves are scored −10..+10 against the active goal's clock, in a named operating mode
  (`scoring.md`).
- Automation and engineering contracts live in `../development/`, not here.
